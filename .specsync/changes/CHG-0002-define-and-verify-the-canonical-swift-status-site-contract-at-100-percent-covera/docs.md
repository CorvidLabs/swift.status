# Docs

The canonical documentation is `specs/status-site/status-site.spec.md`, paired with `specs/status-site/requirements.md`. It describes the rendered URL, package-table columns, Jekyll inputs, integrity constraints, remote dependencies, and failure behavior.

The companion requirements use stable `REQ-STATUS-*` identifiers. They describe only behavior already present in the four authored inputs; they do not claim that remote badges are green or that every linked repository exists.
